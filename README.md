# TiFtesla

TiFgames 3D workshop game: compose and decompose a procedural white-pearl Tesla Model 3-style vehicle.

Click parts in the scene or catalogue to remove them. Switch to Compose to install missing parts again. Drag to orbit and scroll to zoom.

The game is a static site using Three.js from an import map. The vehicle is generated procedurally in `main.js`, so no model download is needed.
