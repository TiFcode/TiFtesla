# TiFtesla

TiFgames 3D workshop game: compose and decompose photoreal-style Tesla vehicles, including Model Y legacy and Model Y Juniper 2025.

Click parts in the scene or catalogue to remove them. Switch to Compose to install missing parts again. Drag to orbit and scroll to zoom.

The game is a static site using Three.js from an import map. Imported GLB assets live under `assets/` with their credits; the procedural workshop model remains available as a fallback.
